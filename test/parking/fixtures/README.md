# 官方回應樣本

2026-10-31 取得的公開資料節錄，用於解析回歸；不是 App 內建資料或即時結果。

- ntpc_static_sample.csv：新北市政府 https://data.ntpc.gov.tw/datasets/B1464EF0-9C7C-4A6F-ABF7-6BDF32847E68 ，只保留解析需要欄位，含重複 ID 及異常混用座標樣本。
- hsinchu_sample.json：新竹市政府 https://hispark.hccg.gov.tw/OpenData/GetParkInfo ，前 3 筆。
- 授權：政府資料開放授權條款第 1 版 https://data.gov.tw/license 。資料節錄或轉換不代表機關背書。
- 新北即時 CSV 在驗證環境回傳 Request Rejected，沒有把拒絕頁當成有效樣本；其動態解析以官方欄位規格的合成測試驗證。
